## 🧰 What is Skipy?

**Skipy** is a web-based, open-source multi-tool built to simplify repetitive and essential tasks for developers, QA engineers, DevOps, and IT professionals.

From shortening URLs to generating secure passwords and simulating data for testing—Skipy brings everything into a single, clean, extensible platform. More tools are constantly being added to improve productivity.

- 🔗 **Frontend**: [https://skipy.click](https://skipy.click)
- ⚙️ **Backend API**: [https://api.skipy.click](https://api.skipy.click)

---

## 🚀 Features

### 🔒 Developer & Security Tools

- **Password Generator**: Secure, customizable password generation.
- **JWT Toolkit**: Create, encode, and decode JSON Web Tokens.
- **Encoder/Decoder**: Convert text between Base64, URL, Binary, and ROT13 formats.
- **URL Validator**: Check URL structure, response status, and validity.

### 📦 Data & Content Utilities

- **Fake Data Generator (Faker)**: Generate names, emails, phone numbers, and more for testing.
- **Credit Card Generator (Test Use Only)**: Generate valid-looking cards for payment testing (Luhn algorithm).
- **JSON Formatter / Validator**: Clean, indent, and validate JSON input.
- **YAML ↔ JSON Converter**: Convert between formats seamlessly for config files or Kubernetes.

### 🌐 Web & Sharing Tools

- **Short Link Generator**: Quickly shorten URLs for sharing.
- **Link Unshortener**: Reveal the original URL behind a short link (generated in Skipy).
- **QR Code Generator**: Convert URLs into QR codes for mobile scanning.
- **Color Palette Generator**: Generate color schemes based on the 60/30/10 rule, ideal for UI designers.
